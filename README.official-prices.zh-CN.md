# Omnivo 官网参考价

`web/public/official-model-prices.json` 是集中维护的公开参考价目录。一个文件可批量更新多个模型，所有模型详情页共用；它不改变 new-api 的实际售价，也不会将任何售价自动乘以 0.8。

当前目录为空。首次开发时供应商官网价格页无法访问，因此没有填入未经核实的数字。没有合格参考价的模型继续展示原有实际价格，不显示确定的折扣。页面通过同源 `/official-model-prices.json` 读取目录，在页面处于前台时每五分钟重新校验。参考价到期会停止显示比较，切回页面时也会重新核对有效期。

## 数据格式

顶层为 `{ "version": 1, "references": [] }`，每条记录使用以下字段：

| 字段 | 要求 |
| --- | --- |
| `modelId` | 与 new-api 公开目录中的实际模型 ID 完全一致；不同版本和别名分别核验 |
| `provider` | 当前可用 `openai`、`anthropic`、`deepseek`、`google`，并与目录中的供应商名称匹配 |
| `currency` | 固定为 `USD` |
| `unit` | 固定为 `million_tokens`，即每百万 token |
| `scope` | 固定为 `standard_text_flat`，仅适用于官网标准文本输入／输出的固定单价 |
| `inputUsdPerMillion` | 官网非缓存文本输入单价，必须为大于零的有限数字 |
| `outputUsdPerMillion` | 官网文本输出单价，必须为大于零的有限数字 |
| `sourceUrl` | 已核验的供应商官网 HTTPS 来源；支持的来源主机列在 `official-pricing.ts` 的 `PROVIDERS` 中 |
| `checkedAt` | 实际核对时间，UTC ISO 8601，例如 `2026-10-24T12:00:00Z` |
| `expiresAt` | 必须晚于核对时间且最多相隔 30 天；超过此时刻停止显示比较 |

同一供应商和模型只能有一条记录。错误字段、非官网链接、重复记录或无效 JSON 会使目录不可用；不从错误数据中挑选有利报价。未来的核对时间、过期记录、供应商或模型名不匹配都不会显示折扣。

## 更新方式

先核对供应商官网的标准按量价格及适用条件，批量生成上述 JSON，再更新该文件。当前 Docker 版本将前端嵌入 Go 二进制，需要重新构建部署：

```bash
docker compose -f compose.local.yml up -d --build --wait
```

资料可由后续的供应商导入程序统一生成，但当前没有自动爬取、官网价格核验或自动调整售价的任务。不得用第三方聚合站的价格直接冒充官网报价。

## 比较范围

Omnivo 价格继续使用 new-api 的模型倍率、输出倍率和当前可用分组。详情页按组分别显示输入和输出的官网价、实际价及差额；指定分组时只比较该组，不自动挑选最低价。实际价相同或高于官网价时也会正常展示。

两列使用相同币种和 token 单位。切换“充值价格”时只折算 Omnivo 价格，官网价仍代表供应商现金报价。分组、币种和倍率来自接口及现有价格设置，不写进公开参考价文件。

本版仅支持标准文本固定单价。阶梯／动态表达式、任务插件和按次计费模型不显示该比较；缓存、批处理、图片、音频、视频和其他附加费用也不在比较范围内。有这些条件的官方报价需扩展结构和场景校验后才能加入，不应压缩成一个通用“省 20%”标签。

## 首页动态折扣

首页不再固定展示“8 折示例”或承诺某个统一折扣。价格区读取与模型目录相同的实际售价，在允许访问目录时每分钟重新请求；对有有效官方参考价的标准文本模型，复用详情页的比较规则，逐分组、逐输入／输出展示当前差额。首页优先展示目录中首个输入、输出在某一可用分组均不高于官网 50% 的模型，标注“精选模型，低至官网 5 折”及适用分组，并保留该模型各组的实际价格对照。多个模型或分组达标时沿用目录顺序，不按最大折扣挑选；没有达标模型时展示首个可比模型并隐藏半价宣传。完整模型价格仍可进入目录查看。

例如同一模型官网参考价保持不变，实际售价从官网价的 80% 调为 50% 后，页面下一次成功取得新价格会从“节省 20%”更新为“节省 50%”，无需修改页面文案或重新构建前端。具体出现时间还取决于后台接口何时返回更新后的价格。刷新失败时不沿用旧的确定折扣，缺少有效参考价时仅显示当前报价入口。

自动刷新展示不等于自动调价：售价继续由 new-api 后台配置，官方参考价仍需核验并集中维护；本实现没有新增官方价格爬取或后台价格调整任务。


分组倍率不是官网折扣。只有模型基础价与官网价一致时，分组倍率 `0.5` 才对应官网 5 折；例如输入、输出基础价都为官网 8 折时，分组倍率 `0.625` 才使两项都达到官网 5 折。页面用当前实际价核对，而不会仅凭倍率值宣传优惠。需要某个模型长期承担半价入口时，应在后台维护该模型的售价及适用组；目前没有指定固定模型 ID，首页按上述条件自动识别。
